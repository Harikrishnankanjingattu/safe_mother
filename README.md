## About

Safe Mother is a machine learning based project that predicts maternal health risk from patient health data.
It classifies the risk into three categories: Low, Mid, and High.

---

## Dataset Features

- Age
- SystolicBP
- DiastolicBP
- Blood Sugar (BS)
- Body Temperature
- Heart Rate
